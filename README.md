# Hole Islands

A ten-level 3D hole-collecting browser game by GameDev.Land.

[Play Hole Islands](https://gamedevland.github.io/hole-islands/) · [GameDev.Land](https://gamedev.land/ru/games/hole-islands/)

Built with TypeScript, Three.js, PixiJS, Cannon physics and GameDevLand Engine. Supports desktop, mobile and tablet layouts.

This repository hosts the compiled web build through GitHub Pages. Source revision and file hashes are recorded in `build-info.json`.
